# Питомец Финни

Мобильное приложение для формирования базовых финансовых навыков у детей 7–11 лет

Техническое задание: Департамент финансов города Москвы, хакатон «Лидеры цифровой трансформации 2026»

---

## О проекте

«Питомец Финни» — образовательное мобильное приложение на Android, в котором ребенок создает виртуального питомца, получает игровую валюту, планирует бюджет, совершает покупки и копит на финансовые цели.

- Целевая аудитория: дети 7–11 лет
- Платформа: Android 8.0+ (API 26+)
- Язык: Kotlin
- Среда: Android Studio
- Хранение данных: SharedPreferences (локально, без сервера)
- Package name: com.topitop.finni_pet_hac

---

## Образовательные цели

Приложение формирует компетенции из Единой рамки компетенций в области финансовой грамотности:

1. Понимание назначения личного бюджета
2. Различение обязательных и необязательных расходов
3. Планирование простых покупок в условиях ограниченного бюджета
4. Постановка краткосрочной финансовой цели и регулярные накопления
5. Оценка собственных финансовых решений
6. Использование мобильного приложения для планирования бюджета при участии взрослого

## Быстрый запуск

### Требования к окружению

- Android Studio: Hedgehog (2023.1.1) или новее
- JDK: 17
- Android SDK: API 26 (Android 8.0) и выше
- Gradle: 8.2
- Kotlin: 1.9.22

### Установка и сборка

1. Клонируйте репозиторий:
   
2. Откройте проект в Android Studio:
   - File → Open → выберите папку проекта
   - Дождитесь завершения синхронизации Gradle

3. Соберите APK:
   - Debug-версия: Build → Build Bundle(s) / APK(s) → Build APK(s)
   - Release-версия: Build → Generate Signed Bundle / APK → APK

4. Установите APK на устройство:
   - Файл находится в app/build/outputs/apk/debug/app-debug.apk
   - Скопируйте на устройство и установите

### Демонстрационный режим

Для экспертной проверки предусмотрен демонстрационный режим:
- На главном экране нажмите кнопку «⏭ Завершить период (Демо)»
- Позволяет пройти 5 игровых периодов подряд без ожидания реального времени
- Каждый период начисляет +1000 монет и снижает показатели питомца

### Сброс профиля

Для повторной демонстрации:
1. Нажмите на иконку настроек в правом верхнем углу
2. Решите арифметический пример (7 + 8 = 15)
3. Нажмите «Сбросить тестовый профиль»
4. Приложение вернется к экрану создания питомца

## Реализованные требования

- 2.5.1 Первый запуск и локальный профиль — Реализовано (CreatePetActivity)
- 2.5.2 Создание виртуального питомца (9 комбинаций) — Реализовано (CreatePetActivity)
- 2.5.3 Главный экран с балансом, накоплениями, целью, заданием, состоянием — Реализовано (MainActivity)
- 2.5.4 Игровая валюта и доход — Реализовано (MainActivity, TasksActivity)
- 2.5.5 Планирование бюджета (3 направления, контроль остатка) — Реализовано (BudgetActivity)
- 2.5.6 Покупки (10 позиций, 2 типа, защита от отрицательного баланса) — Реализовано (ShopActivity)
- 2.5.7 Накопления и цель (3 цели, пополнение, снятие, прогресс) — Реализовано (GoalsActivity)
- 2.5.8 Финансовые задания (6 заданий по 3 темам) — Реализовано (TasksActivity)
- 2.5.9 Последствия и обратная связь — Реализовано (Все экраны)
- 2.5.10 Прогресс и развитие питомца (4 показателя состояния) — Реализовано (MainActivity)
- 2.5.11 История и учебный прогресс — Реализовано (MainActivity, TasksActivity)
- 2.5.12 Раздел для взрослого (барьер + сброс профиля) — Реализовано (AdultActivity)
- 2.5.13 Сохранение состояния и демонстрационный режим — Реализовано (Все экраны)
- 2.5.14 Управление контентом — Реализовано (TasksActivity, ShopActivity)

## Минимальный объем контента

- Комбинации питомца: 9 (3 вида × 3 цвета) — Требуется ≥ 9 
- Игровые периоды: 5 — Требуется ≥ 5 
- Задания по 3 темам: 6 — Требуется ≥ 6 
- Покупки двух типов: 10 — Требуется ≥ 8 
- Цели накопления: 3 — Требуется ≥ 3 
- Стадии развития питомца: В работе — Требуется ≥ 3

## Ключевые UX/UI-решения

- Кремовый фон (#FBF4DF): теплый, дружелюбный
- Скругленные карточки (20dp): мягкий дизайн
- Крупные кнопки (≥ 48×48 dp): удобно для ребенка
- Цветовое кодирование: Зеленый = обязательное, Оранжевый = желаемое, Синий = накопления
- Эмодзи в интерфейсе: визуальные подсказки
- Короткие тексты: возрастная уместность
