Питомец Финни
Мобильное приложение для формирования базовых финансовых навыков у детей 7–11 лет
Техническое задание: Департамент финансов города Москвы, хакатон «Лидеры цифровой трансформации 2026»
________________________________________
О проекте
«Питомец Финни» — образовательное мобильное приложение на Android, в котором ребенок создает виртуального питомца, получает игровую валюту, планирует бюджет, совершает покупки и копит на финансовые цели. Состояние и развитие питомца зависят от финансовых решений пользователя.
Целевая аудитория: дети 7–11 лет Платформа: Android 8.0+ (API 26+) Язык: Kotlin Среда: Android Studio Хранение данных: SharedPreferences (локально, без сервера) Package name: com.topitop.finni_pet_hac
________________________________________
Образовательные цели
Приложение формирует компетенции из Единой рамки компетенций в области финансовой грамотности и финансовой культуры:
1.	Понимание назначения личного и семейного бюджетов.
2.	Различение обязательных и необязательных расходов (необходимое и желаемое).
3.	Планирование простых покупок в условиях ограниченного бюджета.
4.	Постановка краткосрочной финансовой цели и регулярные накопления.
5.	Оценка собственных финансовых решений и объяснение их последствий.
6.	Использование мобильного приложения для планирования бюджета при участии значимого взрослого.

Быстрый запуск
Требования к окружению
•	Android Studio: Hedgehog (2023.1.1) или новее
•	JDK: 17
•	Android SDK: API 26 (Android 8.0) и выше
•	Gradle: 8.2
•	Kotlin: 1.9.22
•	Material Components: 1.11.0
Установка и сборка
1.	Клонируйте репозиторий: git clone https://github.com/augustLight-aa/Finni_pet_hac.git
2.	Откройте проект в Android Studio:
o	File → Open → выберите папку проекта
o	Дождитесь завершения синхронизации Gradle
3.	Соберите APK:
o	Debug-версия: Build → Build Bundle(s) / APK(s) → Build APK(s)
o	Release-версия: Build → Generate Signed Bundle / APK → APK
4.	Установите APK на устройство:
o	Файл находится в app/build/outputs/apk/debug/app-debug.apk
o	Скопируйте на устройство и установите
Демонстрационный режим
Для экспертной проверки предусмотрен демонстрационный режим:
•	На главном экране нажмите кнопку «Завершить период (Демо)»
•	Позволяет пройти 5 игровых периодов подряд без ожидания реального времени
•	Каждый период начисляет +1000 монет и снижает показатели питомца
Сброс профиля
Для повторной демонстрации:
1.	Нажмите на иконку настроек в правом верхнем углу
2.	Решите арифметический пример (7 + 8 = 15)
3.	Нажмите « Сбросить тестовый профиль»
4.	Приложение вернется к экрану создания питомца

Ключевые UX/UI-решения
•	Кремовый фон (#FBF4DF): теплый, дружелюбный, не утомляет глаза.
•	Скругленные карточки (20dp): мягкий, детский дизайн.
•	Крупные кнопки (≥ 48×48 dp): удобно для нажатия ребенком.
•	Цветовое кодирование: Зеленый = обязательное, Оранжевый = желаемое, Синий = накопления.
•	Эмодзи в интерфейсе: визуальные подсказки для детей 7-11 лет.
•	Короткие тексты: возрастная уместность.
•	Защита от перекрашивания темой: использование AppCompatButton + backgroundTintList для стабильности цветов.
